Why it worksSurname in capitals is a different shape from everything else on the row, so it can be found without reading. Names stay anchored to the left edge and above the title, where the eye lands first. Given names are still there, quieter, for Clara vs Robert Schumann.

Trade-offRows get about 8px taller. Upper-case tracked type is the loudest of the three; with 4,880 works it needs restraint (one weight, one size).

B · Name railComposer becomes its own column on the left, set like an index: bold display surname with the given names under it. When neighbouring rows share a composer the name appears once and the rail stays blank beneath it, with a heavier rule between composers. On phones the rail becomes a slim composer header over its rows.

Why it worksNames line up on a single clean edge, so scanning down the left side reads like a list of composers; the title column is free to be about the piece. Deduplication removes the repeated name, which is most of the noise when results are sorted by composer.

Trade-offCosts about 190px of width, so titles wrap more on small laptops (the rail turns into option A below ~1000px). With results sorted by relevance, the names repeat and the benefit is smaller.

Why it worksThe composer is now part of the main line at full title size, so there is no small text to squint at; the heavy surname is the visual anchor and the title follows as in speech. The reference line only has to be good enough to settle ambiguity (and an initial is added when two composers share a surname: C. Schumann).

Trade-offIt changes how the title reads ("Brahms Concerto in D major, Op. 77"), which some will find less formal. The name is no longer a separate column, so screen-reader and sorting semantics need care.
