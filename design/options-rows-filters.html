Rows & filters: options

Part 1 shows four ways to show the level on each row, with today's version for reference. Part 2 shows three ways to bring search and filters together. Every option uses the same works, sorted by composer (the new default), with the stronger composer name. Tags are sample values until the character tags land.

Part 2 · Search and filters, together

Today there are four places to narrow the list: the header search, the sentence, a chip row, and the More drawer. The header search doesn't look connected to the results, and before the tags arrive the chip row is just Major and Minor. Each option below brings these into one place.

A · One toolbar on top of the results RecommendedThe sentence keeps the three big choices (what, setting, level). Right above the list, one toolbar holds the search (“Search within these 59 works”), a Character menu with every vibe tag grouped and counted, Length and More menus, and Sort. Everything that's on shows as a removable chip underneath, so you always see why the list looks the way it does. On the home page the header search disappears, because this one replaces it.

C · The sentence does it allThe finder sentence grows two more blanks: “that feels [any way]” opens the character palette, and “by [anyone]” is a typeahead for a composer or title. It's the most elegant to read, but power filters (length, era, exams) still need a “More” link, and a free-text search is less obvious inside a sentence.

My suggestion: combine Composer groups (4) for the rows with One toolbar (A) for search and filters. The toolbar search filters exactly what you're looking at, the chips under it make every active filter visible and removable, and the Character menu holds all the vibe tags without a lonely Major/Minor row. Composer headings then answer “who wrote this?” before anything else.
